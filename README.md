# Ethiopian Exam Prep Platform

A web platform for Ethiopian students to access past exam papers and prepare for national exams.

## 🎯 Features

- User registration and authentication
- Exam type browsing (Grade 6, 8, 12, Exit Exam, GAT, NGAT)
- Past paper downloads
- Progress tracking (coming soon)
- Interactive quizzes (coming soon)

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express.js
- **Database**: PostgreSQL
- **Authentication**: JWT, bcrypt

## 📋 Prerequisites

- Node.js (v18 or higher)
- PostgreSQL (v15 or higher)
- npm

## 🚀 Installation
